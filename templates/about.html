Project Overview

Placement Prediction System

The Placement Prediction System is an industry-grade machine learning web application designed to predict whether a student will receive a campus placement offer based on their academic performance, work experience, and MBA specialisation.

Built on the Campus Selection dataset, the system trains multiple ML classifiers, evaluates them using 5-fold cross-validation, and automatically selects the best performing model for inference.

The Flask web application provides a professional interface for predictions, analytics, and visualizations, complete with downloadable reports and a comprehensive analytics dashboard.

About the Dataset

The Campus Selection dataset is a well-known binary classification dataset used for predicting campus placement outcomes.

It contains records from MBA students including their academic performance across SSC, HSC, and undergraduate levels, along with work experience, employability test scores, and MBA specialisation. The target variable indicates whether the student was placed.
